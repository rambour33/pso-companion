Installer un skill

  1. Télécharge le .zip du skill ci-dessus.
  2. Décompresse-le dans le dossier .claude\skills du projet (ex. P:\PSO 2\.claude\skills). Le zip contient déjà le dossier du skill : on obtient .claude\skills\companion\SKILL.md.
  3. Dans Claude Code ouvert sur ce projet, tape /companion (ou le nom du skill) pour vérifier qu'il se charge.

Pour l'installer pour tous tes projets, décompresse-le plutôt dans %USERPROFILE%\.claude\skills.
